# examples

This repository also contains examples accompanying the paper [Disciplined Nonlinear Programming](https://stanford.edu/~boyd/papers/dnlp.html) in the `nlp_examples/` directory. Each example demonstrates solving a nonlinear optimization problem using CVXPY.

### How to run the NLP examples
After installing the [DNLP](https://github.com/cvxgrp/DNLP) package you should be able to run the NLP examples.
